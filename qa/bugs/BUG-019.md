## Probable cause
- server/tailorChat.js:174-187 resumeLines() prints only contact, title, summary, experience, education (degree/school/year), skills, certifications. otherSections, projects, volunteer, achievements, publications, languages, interests, references are never sent, so the model cannot see them and (RULES prompt line 295 lists only T, S, E, K ids) answers 'you have no such section'.
- server/tailorChat.js:210 cleanEdit allows only ops on C, T, S, E, K, Z; no edit can target an extra section (src/tailorEdits.js textAt has no id for them).
- There is no guard that compares the reply with the cards (server/tailorChat.js:556-559 only handles blocked edits).

## Suggested fix
1) Add the extra sections to resumeLines with ids (e.g. [O0] Core Competencies: ..., [P0] Projects...) and tell the model which ids are editable. 2) Until an edit op exists for them, give the model a fixed capability list and make it say 'I can't edit <section> here; you can edit it by hand' (or implement set_list ops for them, like set_skills). 3) Server guard: if the message names a section (core competencies, projects, ...) and no returned card targets it, replace the reply with the honest 'cannot' text. 4) Add a reply-vs-cards claim check (qa/llm/lib.mjs claimCheck).
