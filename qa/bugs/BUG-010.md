# BUG-010: Workspace chat sends on Enter on phones, unlike the start-screen composer
Severity: S5
Priority: P2
Status: Verified-Fixed
Flow / TC-ID: Conversation / TC-CHAT-001
Devices: iphone-14 (observed; same code for all phones)
URL: /app/editor workspace
Frequency: Always
Build / env: local scratch copy of branch resume-llm, commit c53d3dc, http://127.0.0.1:5273 (fake Supabase, API mocked, no live keys), 2026-11-24 IST

## Steps to reproduce
1. On a phone, open the workspace and tap 'Ask for a change'.
2. Press Return on the on-screen keyboard.

## Expected
Return adds a new line (as in the start screen composer, which checks pointer: coarse).
## Actual
Return sends the message immediately, so multi-line messages cannot be typed.
## Evidence
- Test: qa/tests/thread.spec.ts (Enter sends on phone projects)

## Probable cause
src/ResumeWorkspace.jsx:70-75 askKeys() has no matchMedia('(pointer: coarse)') check; src/ResumeLLM.jsx:1085 has one.
## Suggested fix
Mirror the coarse-pointer check.
