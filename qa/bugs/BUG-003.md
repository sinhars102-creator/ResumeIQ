# BUG-003: 'Apply all ready' applies suggestions that carry the 'Use Led only if you led this' warning, with no confirmation
Severity: S3
Priority: P1
Status: Verified-Fixed
Flow / TC-ID: Review / TC-REV-010
Devices: laptop-chrome, laptop-safari, laptop-firefox (phone has no Apply all)
URL: /app/editor workspace
Frequency: Always (3/3)
Build / env: local scratch copy of branch resume-llm, commit c53d3dc, http://127.0.0.1:5273 (fake Supabase, API mocked, no live keys), 2026-11-24 IST

## Steps to reproduce
1. Resume bullet 'Assisted with the checkout launch'. Suggestion rewrites it to 'Led the checkout launch' (the card shows the warning).
2. Click 'Apply all ready' at the top.

## Expected
Warned ownership upgrades are skipped or need a confirmation, because the card itself says to dismiss unless true.
## Actual
The bullet becomes 'Led the checkout launch' with no prompt, so one click can put an inflated ownership claim on the resume.
## Evidence
- Screenshot: qa/runs/full/review-Review-and-edits-TC-9e82b--a-warned-ownership-upgrade-laptop-chrome/test-failed-1.png

## Probable cause
src/ResumeLLM.jsx applyAll() (~line 855) picks every pending edit that is 'ready' (no blanks). The warning is computed only in src/ResumeWorkspace.jsx warningOf() (line ~318) at render time.
## Suggested fix
Move the UPGRADE_FROM/UPGRADE_TO test to a shared helper and exclude warned suggestions from applyAll (leave them pending, say how many were left).
