# BUG-006: Copy / Edit / Rerun buttons on the user's messages are 32px tall on phones, and sit below the fold of a very short chat area
Severity: S4
Priority: P2
Status: Verified-Fixed
Flow / TC-ID: Message actions / TC-MSG-008
Devices: iphone-14, iphone-se, pixel-7, budget-android (not a phone-only rule on laptop)
URL: /app/editor
Frequency: Always (4/4)
Build / env: local scratch copy of branch resume-llm, commit c53d3dc, http://127.0.0.1:5273 (fake Supabase, API mocked, no live keys), 2026-11-24 IST

## Steps to reproduce
1. Open a chat with a pasted job description on a phone.
2. Measure the Copy, Edit, Rerun buttons.

## Expected
Tap targets of at least 44px; actions reachable without hunting.
## Actual
Each button is 32px high. On iPhone 14 the resume card takes the top half and the chat shows about 5 lines, so the buttons are off screen until you scroll the small chat pane.
## Evidence
- Screenshot: qa/runs/full/jd-Message-actions-TC-MSG--47479-e-44px-tap-targets-on-phone-iphone-14/test-failed-1.png

## Probable cause
src/ResumeLLM.css .rl-msg-actions button (height/padding).
## Suggested fix
Raise to min-height 44px on (pointer: coarse); collapse the resume card on phones once a chat starts.
