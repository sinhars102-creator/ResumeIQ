# BUG-008: Escape does not close the download / template dialog
Severity: S5
Priority: P2
Status: Verified-Fixed
Flow / TC-ID: Templates & export / TC-TPL-009
Devices: laptop-chrome, laptop-safari, laptop-firefox
URL: /app/editor -> Download PDF
Frequency: Always (3/3)
Build / env: local scratch copy of branch resume-llm, commit c53d3dc, http://127.0.0.1:5273 (fake Supabase, API mocked, no live keys), 2026-11-24 IST

## Steps to reproduce
1. Tap Download PDF.
2. Press Escape.

## Expected
The dialog closes (it is aria-modal).
## Actual
Nothing happens; only the Keep editing button or clicking the backdrop closes it. Focus is also not moved into the dialog.
## Evidence
- Screenshot: qa/runs/full/templates-Templates-previe-af72d-yboard-and-focus-is-trapped-laptop-chrome/test-failed-1.png

## Probable cause
src/DownloadPaywall.jsx: no keydown handler, no focus management.
## Suggested fix
Add an Escape handler and move focus into the dialog on open.
