# BUG-005: White screen with no recovery when a saved suggestion points at a resume line that no longer exists
Severity: S3
Priority: P1
Status: Verified-Fixed
Flow / TC-ID: Review / state / TC-REV-013
Devices: all 7 projects
URL: /app/editor
Frequency: Always (7/7)
Build / env: local scratch copy of branch resume-llm, commit c53d3dc, http://127.0.0.1:5273 (fake Supabase, API mocked, no live keys), 2026-11-24 IST

## Steps to reproduce
1. Have a saved chat whose suggestion targets a missing role or bullet (for example E7B9; can happen after a cross-device sync or a changed resume).
2. Open /app/editor.

## Expected
The bad suggestion is ignored or hidden and the page loads.
## Actual
Blank page. Console: 'Cannot read properties of undefined (reading "bullets")'. The bad suggestion is in the saved chat, so reload shows the same blank page; the user has to clear site data. There is no error boundary around the Resume LLM page.
## Evidence
- Screenshot: qa/runs/full/review-Review-and-edits-TC-88ad5-ine-does-not-crash-the-page-laptop-chrome/test-failed-1.png
- Phone: ...-iphone-14/test-failed-1.png

## Probable cause
A render path in src/ResumeWorkspace.jsx or src/tailorEdits.js (applyEdit / captureUndo at lines ~44-99) reads r.experience[i].bullets without checking the role exists. No <ErrorBoundary> in src/App.jsx or src/main.jsx.
## Suggested fix
Drop suggestions whose target does not resolve (textAt(resume, target) == null) when loading a chat; add an error boundary with a 'Start a new chat' button.
