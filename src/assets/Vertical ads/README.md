# Vertical ads (9:16)

608×1080 versions of the four ad designs (YouTube Shorts, Demand Gen vertical): headline, device
mockup, and a green tagline band – no buttons, input fields or browser frames.

Any other size: `npm run ads -- --size=WIDTHxHEIGHT --out="src/assets/Vertical ads"` (layout is picked from the shape).
